# 🧑‍💻✅ Teste de Usabilidade — VigiA-SUS

---

### 🎯 Objetivo do teste

| Item                              | Preencher ✍️                                                                                                                                                                                                                             |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🎯 Objetivo                       | Avaliar se a interface do VigiA-SUS é compreensível, organizada e fácil de usar para execução dos principais fluxos do MVP, como login, análise de risco, consulta territorial, validação de insumos e acesso às informações do projeto. |
| ✅ Hipóteses (o que esperamos)     | Espera-se que os participantes consigam acessar o sistema, identificar os módulos principais, executar uma análise de risco, consultar áreas/ovitrampas e validar um arquivo CSV com pouca ou nenhuma ajuda.                             |
| 📌 Escopo (telas/funcionalidades) | Login, Dashboard Preditivo, Gestão Territorial, Importação de Insumos e Sobre o Projeto.                                                                                                                                                 |

### 🧩 Tarefas (roteiro do teste)

| 🏷️ Tarefa | 📝 Descrição                                                                             | 🎯 Sucesso (critério)                                                                                      | ⏱️ Tempo alvo | ⭐ Prioridade |
| ---------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ------------- | ------------ |
| T1         | Realizar login no sistema com usuário e senha informados pelo avaliador.                 | Participante consegue acessar a plataforma e visualizar seu perfil/módulos.                                | Até 2 min     | 🔥 Alta      |
| T2         | Acessar o Dashboard Preditivo, preencher os parâmetros e executar o motor de inferência. | Participante consegue executar a análise e identificar o resultado de risco exibido.                       | Até 4 min     | 🔥 Alta      |
| T3         | Acessar Gestão Territorial e localizar a lista de áreas monitoradas.                     | Participante consegue visualizar áreas cadastradas, status e informações principais.                       | Até 3 min     | ⚠️ Média     |
| T4         | Consultar ovitrampas por área monitorada.                                                | Participante consegue selecionar uma área e visualizar os indicadores de armadilhas.                       | Até 3 min     | ⚠️ Média     |
| T5         | Acessar Importação de Insumos e validar um arquivo CSV.                                  | Participante consegue identificar o tipo de insumo, enviar arquivo e compreender o resultado da validação. | Até 5 min     | 🟦 Baixa     |
