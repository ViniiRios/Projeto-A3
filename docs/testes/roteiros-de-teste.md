## Observação

Os roteiros foram executados na versão final do MVP do VigiA-SUS, com backend Java, serviço Python, banco PostgreSQL e interface Streamlit em ambiente local.

As evidências dos testes manuais foram registradas em `docs/evidencias-finais/manuais/`, mantendo a numeração dos arquivos para facilitar a organização e a rastreabilidade.
